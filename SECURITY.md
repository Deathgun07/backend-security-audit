# Security policy

## Reporting a vulnerability in this project

If you find a security issue in the skill itself (for example, an installer that could write outside the intended folder, a script that could leak a secret value, or an instruction that could make an assistant modify the audited code), please **do not open a public issue**.

Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository. You should get an answer within 7 days.

## Scope

This project is a defensive, read-only analysis tool. Vulnerabilities found **by** the skill in your own projects are not vulnerabilities of this project: fix them in your code, using the report.

## Supported versions

Only the latest release receives fixes.
